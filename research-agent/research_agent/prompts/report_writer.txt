<report_json>
files/reports/report.json holds every word of the report. Both formats are built from it, so they always match.

```json
{
  "title": "Global EV Market 2026",
  "subtitle": "Who is gaining share, and why",
  "meta": "Report date: 10 November 2025. Evidence as of 2025-11-10. Facts from fact_check/verified_facts.md.",
  "summary": ["Two to four sentences of executive summary, with citations [1] [2]."],
  "verification": {"confirmed": 31, "corrected": 4, "false": 1, "unverified": 6},
  "sections": [
    {"heading": "Key findings", "blocks": [
      {"type": "p", "text": "Tesla held **19.5%** of the market in 2024 [1]."},
      {"type": "bullets", "items": ["Finding with a statistic [2]", "Another finding [3, 4]"]},
      {"type": "table", "header": ["Company", "Share", "Change"], "rows": [["Tesla", "19.5%", "-1.2%"]]},
      {"type": "chart", "id": "ev_market_share", "caption": "Market share, 2024 [1]."},
      {"type": "image", "src": "files/charts/ev_pie.png", "caption": "Only for a PNG with no charts.json entry."}
    ]},
    {"heading": "Proposed approach", "tag": "Untested proposal", "blocks": []},
    {"heading": "Verification", "blocks": []}
  ],
  "sources": [{"title": "NOAA 2026 Hurricane Season Outlook", "url": "https://www.noaa.gov/..."}],
  "further_reading": [{"title": "Regional coverage of the season", "url": "https://www.example.com/..."}]
}
```

- Text may use **bold**, [link text](https://...) and citations [n] or [n, m], where n is the source's position in "sources" (1-based)
- verification: the counts per verdict from files/fact_check/ledger.md
- tag: optional short caution label on a section, e.g. "Untested proposal" or "In-sample only"
- chart: "id" is a key in files/data/charts.json (the PNG's file name without .png). Use a chart block for every chart that has an entry there
- A source with no URL (a local file) is {"title": ..., "path": "..."}; never cite a web source without its URL
- Write numbers in table cells as text exactly as they should appear ("19.5%", "$2,088")
</report_json>

<pdf_generation>
build_report.py loads report.json and lays it out with reportlab. Here's the pattern:

```python
import json
import os
import re
from pathlib import Path
from xml.sax.saxutils import escape
from reportlab.lib.pagesizes import letter
from reportlab.lib.styles import getSampleStyleSheet, ParagraphStyle
from reportlab.lib.units import inch
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, Image, Table
from reportlab.lib.enums import TA_JUSTIFY

R = json.loads(Path("files/reports/report.json").read_text(encoding="utf-8"))
SOURCES = R["sources"]
FURTHER_READING = R.get("further_reading", [])
PDF_PATH = "files/reports/topic_report_YYYYMMDD.pdf"

def link(url, text=None):
    """Clickable external link. escape() is required: a raw & in a URL breaks reportlab markup."""
    return f'<a href="{escape(url, {chr(34): "&quot;"})}" color="blue"><u>{escape(text or url)}</u></a>'

def cite(n):
    """In-text citation [n] that jumps to source n in the Sources section."""
    return f'<a href="#src{n}" color="blue">[{n}]</a>'

def markup(text):
    """report.json text to reportlab markup: **bold**, [text](url) and [n] citations."""
    s = escape(text)
    s = re.sub(r"\*\*(.+?)\*\*", r"<b>\1</b>", s)
    s = re.sub(r"\[([^\]]+)\]\((https?://[^)\s]+)\)", lambda m: link(m.group(2), m.group(1)), s)
    return re.sub(r"\[(\d+(?:\s*[,;]\s*\d+)*)\]",
                  lambda m: " ".join(cite(int(n)) for n in re.split(r"\s*[,;]\s*", m.group(1))), s)

doc = SimpleDocTemplate(PDF_PATH, pagesize=letter, rightMargin=72, leftMargin=72, topMargin=72, bottomMargin=72)
styles = getSampleStyleSheet()
styles.add(ParagraphStyle(name='Justify', alignment=TA_JUSTIFY, fontSize=11, leading=14))
story = [Paragraph(escape(R["title"]), styles['Title']), Spacer(1, 0.25*inch)]

story.append(Paragraph("Executive Summary", styles['Heading1']))
for p in R.get("summary", []):
    story.append(Paragraph(markup(p), styles['Justify']))

for section in R["sections"]:
    story.append(Paragraph(escape(section["heading"]), styles['Heading1']))
    for b in section["blocks"]:
        if b["type"] == "p":
            story.append(Paragraph(markup(b["text"]), styles['Justify']))
        elif b["type"] == "bullets":
            for item in b["items"]:
                story.append(Paragraph(f"• {markup(item)}", styles['Justify']))
        elif b["type"] == "table":
            # Right-align every numeric column (TableStyle ALIGN RIGHT) and wrap cells in Paragraphs.
            ...
        elif b["type"] in ("chart", "image"):
            path = f"files/charts/{b['id']}.png" if b["type"] == "chart" else b["src"]
            if os.path.exists(path):
                story.append(Image(path, width=5*inch, height=3*inch))  # keep the PNG's aspect ratio
                story.append(Paragraph(markup(b.get("caption", "")), styles['Normal']))
        story.append(Spacer(1, 0.1*inch))

# Sources section: every entry is an anchor target and a clickable URL
story.append(Spacer(1, 0.3*inch))
story.append(Paragraph("Sources", styles['Heading2']))
for n, s in enumerate(SOURCES, 1):
    where = link(s["url"]) if s.get("url") else escape(s.get("path", ""))
    story.append(Paragraph(f'<a name="src{n}"/>[{n}] {escape(s["title"])}: {where}', styles['Normal']))

# Further reading: clickable, unnumbered, and clearly separated from the sources
if FURTHER_READING:
    story.append(Spacer(1, 0.2*inch))
    story.append(Paragraph("Further reading", styles['Heading2']))
    story.append(Paragraph(
        "Related coverage gathered during research but not independently verified. "
        "No figure in this report relies on these sources.", styles['Normal']))
    for s in FURTHER_READING:
        story.append(Paragraph(f'• {escape(s["title"])}: {link(s["url"])}', styles['Normal']))

doc.build(story)
print(f"PDF saved to: {PDF_PATH}")
```

<link_check>
After doc.build(), confirm the PDF really contains clickable links. Put this at the end of build_report.py, after doc.build():

```python
pdf = Path(PDF_PATH).read_bytes()
external = len(re.findall(rb"/S /URI", pdf))
internal = len(re.findall(rb"/Dest", pdf))
print(f"external links: {external}, citation links: {internal}")
assert external >= len([s for s in SOURCES if s.get("url")]) + len(FURTHER_READING), "Sources or further reading are not all clickable"
assert internal > 0, "In-text citations are not linked"
```

If either assertion fails, fix the script and rebuild. Do not report success until it passes.
</link_check>
